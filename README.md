# above-us
Астрономический сайт для исследования звёздного неба, отслеживания космических событий и изучения объектов Солнечной системы.

Тема курсовой работы: "Использование фреймворка Dash для создания астрономического сайта"
Будут реализованы следующие функции:
1. **Фото дня NASA (APOD)** — ежедневное астрономическое изображение с описанием от NASA.
2. **Новости и события** — лента космических новостей и предстоящие астрономических явлений.
3. **Справочник объектов** — информация о звёздах, созвездиях и планетах: характеристики, координаты, факты.
4. **Интерактивная карта неба** — карта звёздного неба с поиском и возможностью кликать по объектам.
5. **Отслеживание МКС в реальном времени** — положение Международной космической станции на карте с обновлением каждые несколько секунд.
6. **Генерация карты неба по дате** — создание персонализированного изображения звёздного неба для выбранной даты и места.
7. **Астрономический календарь** — список событий с фильтрацией по дате и типу.

| Компонент | Технология |
|---|---|
| Язык | Python 3.11+ |
| Фреймворк | Dash |
| Астрономические расчёты | Skyfield, Starplot |
| База данных | SQLite |
| Внешние API | NASA APOD, Open Notify, Sunrise-Sunset |
| Стили | CSS / Dash Bootstrap Components |
